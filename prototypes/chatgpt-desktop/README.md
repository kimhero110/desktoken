# WP-003 隔离交互原型 · ChatGPT 桌面精简菜单与设置

交互原型 · 使用示例数据 · 不连接实际应用。

## 启动

直接用浏览器打开本目录的 `index.html`（本地 file:// 加载，无需构建、无需安装）。
四个文件均为普通文件：`index.html`、`prototype.css`、`scenarios.js`（合成场景与固定样例，defer）、`prototype.js`（内存状态与事件，defer）。

页面自带严格 CSP（`default-src 'none'; script-src 'self'; style-src 'self'; ... connect-src 'none'`）。
个别浏览器若因 file:// 策略阻止同目录脚本/样式加载，属于环境限制：请如实记录，不要为此引入外部托管或放开网络。

视觉基线（R4）：Segoe UI Variable Text / Segoe UI 字体栈；背景 #1b1b20、卡片 #22222a、控件 #2a2a32、主色 #2d4f8f；控件圆角 4px / 面板圆角 8px；显式 `color-scheme: dark`；全局 `[hidden]{display:none!important}` 防止 flex/grid 规则使隐藏元素漏显。正文 14px / 辅助 12px、命中目标 ≥28px、文本对比 ≥4.5:1 保持不变。评审工具折叠在“评审工具”details 中（默认收起），演示横幅始终可见。

布局（R4 修正）：设置窗口可见时参与常规文档流（640×520、水平居中、顶部为悬浮条预留 56px 间距），不再绝对定位上移出画框；面板可见时通过 `:has()` 为桌面预留 悬浮条间距+480px 高度，仅悬浮条模式下桌面保持紧凑最小高度；关于/接入说明子面板宽度 `min(400px, 可用宽度)`。不支持 `:has()` 的环境下面板高度预留退化为溢出可见（页面可滚动，不裁切）。

## 边界（必须遵守）

- 无网络（无 fetch/WebSocket/EventSource/sendBeacon）、无 Tauri IPC、无系统通知、无剪贴板写入、无 localStorage/sessionStorage/IndexedDB、无文件写入、无安装或应用激活。
- 全部数据为内存中的合成样例；关闭页面即回滚，刷新恢复固定初始样例（S01）。“重置演示”= 重新加载页面。
- 输入框仅供合成示例值，请勿输入真实数据；错误只输出固定码与预设文本。
- 不读取本目录之外的任何文件、凭据或配置。

## 评审框架（画框外，不计入产品操作）

- 场景选择：12 个固定场景（S01–S12），每个含说明与预期；切换会清除该场景的事件与合成时钟，保留演示导航。
- 视图快捷：悬浮条 / 面板 / 设置（评审直达入口）。
- 时钟快进 1 分钟（演示）：推进合成时钟，用于观察暂停倒计时、冷却到期。
- 产品操作计数：画框内交互（点击 / 右键 / 键盘等效）各计 1 次，用于核对五流程点击预算；可归零。
- 重置演示：重新加载页面，恢复初始样例并清空草稿。

## 状态模型

- `connectionState`：unverified / absent / conflict / observable_demo / disconnected / unsupported_demo。连接边界单独显示。
- 额度与连接解耦：额度摘要来自独立额度来源（官方额度页 / API 平台示例开关），与 ChatGPT 连接状态无关；来源全停用时才显示“未知（示例额度来源已停用）”。
- `taskState`：unknown / working / needs_attention（授权/输入细分）/ ended / cancelled / failed_demo。仅合成枚举，来自场景 fixture。断连不推断任务失败或完成——不可靠连接下任务状态为 unknown，历史事件仅作保留；显式“失败（演示）”只允许出现在可靠的 observable_demo 来源下的任务错误。
- 并发与旧代规则（S12）：由纯事件 reducer（`QuotaBarDemoLogic.reduceTaskEvents`，taskId+generation 键控）回放；同一任务 SAMPLE-C 的 G1 取消后 G2 开始、旧代 G1 结束晚到时，当前任务列表仅含每任务最新一代（`currentTasks`），旧代 G1 归入历史（`historyTasks`，另见事件记录），不产生第二条当前任务记录。S12 当前 3 项 = A 已结束、B 工作中、C(G2) 工作中，摘要“工作中 2 · 已结束 1（演示）”；有任务工作中时绝不显示全局已结束。迷你工作摘要优先显示等待确认（等 N），其次工/结/消/失。
- 提醒与连接解耦：总开关关闭 / 暂停不产生演示提交事件且事件留存；系统勿扰标“可见性未确认”，API 失败标“提交失败”，均不把连接变红。
- 暂停使用注入的合成时钟（固定基准 10:00:00 + 内存偏移），不读写系统时钟、不持久化。
- 自定义来源字段语义：认证头为头名称（如 `Authorization`）；前缀为原样保留的令牌前缀（如 `Bearer `，含尾随空格，不去除）；窗口映射为竖线分隔 `标签 | 已用字段 | 限额字段或字面量 | 重置字段(可选) | invert(可选)`，字段用点路径（如 `data.used`），保存时校验（ERR_WINDOW_MAPPING / ERR_POLL_RANGE 为固定演示错误码）。

## 键盘

- 设置页签：方向键 / Home / End；Tab 可达全部控件（含折叠区：额度来源、已有工具、诊断、高级自定义）。
- 悬浮条：Enter/Space 展开面板；菜单键（或 Shift+F10）打开右键菜单。
- 右键菜单：上下键移动、右键进入子层、左键/Esc 返回上层并回焦父项、Esc 再退出整个菜单；子层仅 1 层。
- 面板暂停弹层（role=menu）：打开即聚焦首项，上下键循环移动、Home/End 跳转（roving tabindex，单表位点）；Enter/Space 原生激活；Esc 仅关闭本层（不冒泡连关面板）并回焦“暂停提醒”按钮；Tab 关闭弹层后按自然顺序离开，无焦点陷阱；暂停/恢复后焦点稳定回到触发按钮。
- 弹层（菜单 / 暂停选择 / 关于 / 接入说明 / 全部记录 / 设置 / 面板）：Esc 关闭并回到触发元素。
- 不存在焦点陷阱；关闭面板不强行聚焦其它程序。
