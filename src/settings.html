本机任务 · 试验功能

仅监控当前电脑。先生成配置查看内容，再点击安装或手动合并，之后重启对应工具。安装会备份原文件并保留其他设置；不会批准工具操作。长时间无事件显示“状态未知”。
配置绑定当前 QuotaBar 可执行文件路径，移动程序后需重新生成。已使用 QuotaBar 插件时，请勿重复安装用户钩子。Kimi Code、OpenClaw、Antigravity 尚未接入。
ChatGPT 桌面端：设置 → Coding → Hooks → QuotaBar（插件来源名为 QuotaBar；此处安装的是「用户配置」用户钩子），审核并信任钩子后才会上报任务状态；安装或开启开关不等于已信任，钩子定义更新后可能需重新审核。
仅检查默认用户配置文件，不检查插件来源（QuotaBar）的信任状态。配置匹配不等于已经登录。系统通知还受勿扰模式影响。

平台凭据

自定义监视（开放框架）

任何"一个 GET 请求返回 JSON 额度"的平台都可以接入：填端点、认证头、JSON 路径映射（点语法，如 data.limits.0.percentage）。limit 路径也可直接填数字（参考额度，用于只报"已用/余额"的接口）；行尾加第 5 段 invert 进入低水位模式（余额越剩越少，条越红、越告警）。
