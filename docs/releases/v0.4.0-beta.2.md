# QuotaBar v0.4.0-beta.2 — 本机任务监控预览

本版本为开发预览版，[v0.3.2 稳定版下载](https://github.com/kimhero110/desktoken/releases/tag/v0.3.2)继续保留，GitHub 发布页的「Latest」标记保留在稳定版。额度功能保留，本版聚焦本机任务状态的显示修正与 ChatGPT 桌面端接入指引。

## 接入范围

- **OpenCode V1**：真实工作、等待授权、拒绝后结束已实测（沿袭 beta.1）。
- **ChatGPT 桌面端**：用户钩子路线本机验证——工作事件链路实测打通；等待授权、恢复与结束经用户报告验证；等待输入及全部权限模式未验证。插件路线为本机原型：需从源码单独打包，未随发布包提供；插件配置就绪（8 个钩子启用且已信任）只证明配置，未捕获到实际事件，不记为桌面执行已验证。
- **Codex CLI / Claude Code**：提供 hook 配置与诊断；真实会话验收状态与 beta.1 相同。
- Kimi Code、OpenClaw、Antigravity、OpenCode V2 尚未接入；macOS 任务监控未实机验收。

## 本次改动（相对 beta.1）

- 修复 Kimi 5h 窗口缺少 used 字段时不显示的问题，按有效的总量与剩余额度推导使用量。

- 任务列表诚实显示：项目名加「项目：」前缀，不再冒充任务标题；「本轮已停止」改中性灰，不再用成功绿暗示完成；会话 ID 显示最短唯一前缀。见 [显示语义](https://github.com/kimhero110/desktoken/blob/v0.4.0-beta.2/docs/task-display-semantics.md)。
- ChatGPT 桌面端 Hooks 审核指引：设置 → Coding → Hooks 中审核信任；插件与用户钩子二选一，避免一事两报；配置检查不代替信任审核。
- 桌面端探查与插件原型证据归档：[探查记录](https://github.com/kimhero110/desktoken/blob/v0.4.0-beta.2/docs/codex-desktop-probe.md)、[插件说明](https://github.com/kimhero110/desktoken/blob/v0.4.0-beta.2/docs/codex-plugin.md)。

## 安装与切换

下载程序不会自动接入任务状态。首次使用：QuotaBar 设置 → 本机任务 → 生成配置 → 查看并安装用户钩子；ChatGPT 桌面端再到设置 → Coding → Hooks → 用户配置，审核并信任 QuotaBar 条目。若单独使用 QuotaBar 插件，则在 QuotaBar 插件来源下审核，不重复安装用户钩子。重启对应工具后开始新任务验证。

- Windows 可选安装包 `QuotaBar_0.4.0-beta.2_x64-setup.exe` 或绿色单文件 `quotabar.exe`；macOS 见发布页 DMG（架构以文件名为准）。
- 稳定版与预览版共用同一份设置与数据，不做隔离；切换时同一时刻只运行一个 QuotaBar：先退出旧版，再启动新版。覆盖安装前退出旧 QuotaBar。
- 移动程序后需重新生成并安装接入；不要直接覆盖已有工具配置。
- `checksums-*.txt` 提供 SHA-256 校验值，构建附带 provenance attestation。

详见 [接入和限制](https://github.com/kimhero110/desktoken/blob/v0.4.0-beta.2/docs/task-monitor.md)、[更新日志](https://github.com/kimhero110/desktoken/blob/v0.4.0-beta.2/CHANGELOG.md)。
