# QuotaBar v0.4.0-beta.1 — 本机任务监控预览

本版本为预览版，v0.3.2 仍是稳定版。额度功能保留，新增本机任务状态和可选桌面提醒（默认关闭）。

## 接入范围

- **OpenCode V1**：真实工作、等待授权、拒绝后结束已实测。
- **Codex CLI**：提供 hook 安装和诊断；已安装不等于已信任，真实会话尚未通过验收。
- **Claude Code**：提供 hook 配置，登录后的完整流程尚未验证。
- **ChatGPT 桌面端未接入；Codex 桌面端未验证。请勿将 CLI 接入视为桌面端支持。**
- Kimi Code、OpenClaw、Antigravity、OpenCode V2 尚未接入；macOS 任务监控未实机验收。

## 本次改动

- 本机任务页、工作/等待/结束/异常/未知状态、多会话隔离和去抖提醒。
- 接入预览、一键安装/移除、原配置备份、命令行安装及诊断。
- 修复会话关闭取消结束提醒、并行授权误恢复、文件暂时不可读导致事件丢失等 9 项问题。
- Windows 配置替换及备份保留 DACL、所有者、组及继承保护；异常退出释放安装锁。
- 原生合成验收覆盖三会话、7 次通知候选；加入 Windows CI。通知 API 成功不代表弹窗可见性已验证。

## 安装与验证

Windows 可选安装包或 `quotabar.exe`；macOS 可选 DMG（架构见文件名）。移动程序后重新生成并安装接入；覆盖安装前退出旧 QuotaBar。不要直接覆盖已有工具配置。

`checksums-*.txt` 提供 SHA-256 校验值，构建附带 provenance attestation。

详见 [接入和限制](https://github.com/kimhero110/desktoken/blob/v0.4.0-beta.1/docs/task-monitor.md)、[更新日志](https://github.com/kimhero110/desktoken/blob/v0.4.0-beta.1/CHANGELOG.md)。
