# QuotaBar v0.3.3 — stable 维护版

日期：2026-09-09。基于 stable v0.3.2 的维护发布，只带两项修复，其余保持
v0.3.2 原样。

## 修复内容（仅此两项）

1. **原生进程发现（Windows）**
   - Antigravity 语言服务器的发现不再拉起 PowerShell 子进程，改为原生
     WMI 进程查询 + 系统 TCP 监听表。行为不变，后台更干净。

2. **安全 Startup 自启（Windows）**
   - 开机自启改用用户 Startup 文件夹里的 `QuotaBar.lnk`，程序启动时
     不再写注册表。
   - 迁移失败时不静默：会报告具体的权限不足或同名冲突原因，
     修复后重新切换开关即可重试（仅限指向本程序的那条，
     指向其他程序的同名项会报错保留，不会误删）。

## 不包含

- **任务监视**（UI / hooks / CLI）等 beta 功能不在 stable 线，如需请用
  beta 渠道。

## 下载

- Windows 安装包：`QuotaBar_0.3.3_x64-setup.exe`
- Windows 便携版：`quotabar.exe`
- macOS：`QuotaBar_0.3.3_<arch>.dmg`（架构以 Release 附件实际文件名为准）
- 校验：`checksums-*.txt`（SHA-256）；构建来源见 Release 的
  *Attestations* 标签页。

升级沿用旧版资产：绿色 exe 直接替换，安装包覆盖安装保留设置；
设置/历史/凭据位置不变。

## 测试与安全说明

- 回归测试：Rust 89 通过 / 0 失败，前端 4 通过 / 0 失败（均使用临时
  目录/一次性注册表子键，不碰真实 Startup 文件夹和真实 Run 键）。
- 实机验收未报告：stable 线的实机 UI、自启动开关与 Antigravity
  端到端表现暂无已报告的验证结果，此处不作任何虚构的验收声明。
- **本地测试二进制**：本地构建的分发包已通过 Windows Defender 定向
  扫描（found no threats，实时保护开启，情报版本 1.459.111.0）。
  注意：这是对本地构建的测试结果，**不代表**对本 Release 由 CI 产出的
  二进制的任何厂商判定；CI 产物请自行用上述 checksums 与证明核对。
- **未签名**：无代码签名证书；依设备信誉与策略不同，安装或首启时可能
  出现安全提示，也无法保证任何杀软在任何时候都不误报。

## 正式附件验证

GitHub Actions 的 Windows 与 macOS 构建均成功。下载的五个正式附件均与 GitHub SHA-256 摘要一致；Windows 安装包的构建来源证明验证通过。对正式分发目录执行 Defender 扫描返回 found no threats（实时保护开启，情报版本 1.459.111.0）。这些结果不等于 Microsoft 对旧 beta.2 检测作出误报判定，也不替代实机功能验收。
