# v0.3.3 — stable 维护版（本地测试包）

日期：2026-09-09。基于 stable v0.3.2 的干净 worktree，仅回移两项已在 beta3
验证过的修复。**本页描述的是本地测试包，尚未发布；公开 Release 下载链接待
正式发版后再补。**

## 回移内容（仅此两项）

1. **原生进程发现（Windows）** — `src-tauri/src/providers/gemini.rs`
   - 旧：Antigravity 语言服务器发现拉起 `powershell -NoProfile ...`
     子进程（Get-CimInstance + Get-NetTCPConnection 脚本）。
   - 新：WMI COM 查询（`Win32_Process`，按进程名过滤，仅取
     ProcessId + CommandLine 两个属性）+ `GetExtendedTcpTable` 原生 TCP
     监听表（IP Helper，owner-PID）。全程无 shell 子进程。macOS/Linux
     的 ps/lsof 路径保持不变。
   - 参照 beta3 已编译验证的实现，锁定依赖 `wmi 0.15.2`、
     `windows 0.61.3`（与 beta Cargo.lock 相同版本）。

2. **安全 Startup 自启（Windows）** — `src-tauri/src/autostart.rs`（新增）
   - 旧：HKCU `...\Run` 写 `QuotaBar` 值，且**每次程序启动都同步写一次**。
   - 新：用户 Startup 文件夹里的 `QuotaBar.lnk`（IShellLinkW + IPersistFile
     Shell COM 写入；无 WScript.Shell、无 PowerShell）。正常启动**从不**
     写自启状态，唯一变更路径是设置页的自启动开关。
   - 所有权规则：只拥有 `QuotaBar.lnk` 这一个产物。已存在但指向其他程序
     （或读不出来）的同名快捷方式 → 冲突报错，不覆盖、不删除。
   - 旧版迁移：仅在用户显式开关自启动时，匹配本程序可执行文件的旧 Run
     值才会被删除；指向其他程序的同名 Run 值视为冲突，报错并保留原样。

## 明确不包含（非目标）

- **任务监视**（UI/hooks/CLI）及其他 beta 功能一律未回移。
- stable 现有 provider 行为、UI 行为、macOS 行为均保持 v0.3.2 原样。

## 资产与兼容

- 旧 stable（≤0.3.2）的安装与资产全部沿用：设置/历史/凭据位置不变，
  绿色 exe 直接替换，安装包覆盖安装保留设置。
- 升级后旧的 Run 自启项在用户下次显式开关自启动时按上述迁移规则清理；
  在此之前它继续生效。若清理步骤失败（快捷方式已创建但 Run 值未删成），
  可能出现两处自启并存，再次执行开关即可收敛。
