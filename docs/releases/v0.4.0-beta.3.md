# QuotaBar v0.4.0-beta.3 — Windows 原生调用与启动修复

这是开发预览版，保留额度与本机任务状态功能。[v0.3.2 稳定版](https://github.com/kimhero110/desktoken/releases/tag/v0.3.2)及其原附件、Latest 标记继续保留。

## 本次更新

- Antigravity 探测改用原生 Windows WMI 和 TCP 表 API，不再启动 PowerShell。
- Windows 任务钩子去掉 PowerShell 包装：Codex 使用宿主命令机制，Claude 使用程序路径与参数直接启动接收器。
- 开机自启改为用户 Startup 快捷方式，主程序正常启动不再写 Run 项。用户调整开关时才迁移匹配旧项；冲突项保留并提示错误。

## 升级要做的一步

先从托盘退出旧 QuotaBar，再安装或运行新版。稳定版与预览版共用本地设置和数据。

**重新生成接入配置，并在桌面端设置 → Coding → Hooks 审核信任新的 QuotaBar 钩子。** 旧 beta.2 的 PowerShell 配置不会随 exe 自动更新；若使用个人 QuotaBar 插件，需重新生成插件内容。插件与用户钩子二选一，避免重复事件。程序不会代替你写入信任。

## 验证与边界

- 原生改造代码已通过 123 项 Rust 测试、43 项前端测试；本地发布构建的事件桥、三个会话生命周期测试通过。
- 发布前本地 beta.3 测试包：Defender 实时保护开启、情报版本 1.459.111.0，扫描未发现威胁；用户实测启动不闪黑窗、未被拦截。
- 上述用户实测针对本地测试包；本发布附件由 GitHub Actions 从版本标签重新构建，有独立哈希与构建来源证明，不能视为同一二进制。
- 迁移后真实桌面任务的完整状态流、所有权限模式、Antigravity 实际额度回归及 macOS 实机测试仍待验证。本版本继续标为预发布。
