# v0.4.0-beta.2 发布验证

2026-09-08 发布为开发预览版，不替代 v0.3.2 稳定版。

- 版本源提交：`edf4fa2`，标签 `v0.4.0-beta.2`；Cargo、锁文件与 Tauri 版本一致。
- 本地测试：114 项 Rust、43 项 Node 全部通过。
- [GitHub CI](https://github.com/kimhero110/desktoken/actions/runs/34209580671) 通过，含原生任务桥接与生命周期检查。
- [发布构建](https://github.com/kimhero110/desktoken/actions/runs/34209580821) Windows、macOS 全部通过，产物附 SHA-256 与构建来源证明。
- 从 GitHub 下载的 Windows 绿色版、Windows 安装包、macOS aarch64 DMG 均匹配发布校验文件。
- 下载后的 Windows 绿色版通过隔离的合成原生生命周期检查：3 个会话、7 次通知候选。这不代表真实桌面插件或通知可见性完成验收。
- GitHub 开发版已公开，`isDraft=false`、`isPrerelease=true`；Latest 仍为 `v0.3.2`。
- 原稳定版附件 ID、digest、size、URL 与时间戳和发布前一致，仅下载计数因验证下载发生变化。
- Gitee 已补齐 v0.3.2 Windows 稳定版镜像，v0.4.0-beta.2 同步 Windows 安装包、绿色版、macOS DMG 与两份校验文件。开发版标题和说明明确预览用途并链接稳定版。
- README 下载对照表分别固定到两个版本，不使用会随 Latest 漂移的开发版地址。
