交付文件预定：index.html（演示框架+各视图）、prototype.css、prototype.js（内存状态及事件）、scenarios.js（固定样例）、README.md（启动/边界/走查）、acceptance.md（实际结果）。不新增构建依赖，普通 defer 脚本可直接打开本地 HTML。可选测试脚本放同目录；不得引入正式服务或下载依赖。

## 2. 信息架构和几何约束

默认打开设置示例，设置三页仅“连接 / 提醒 / 外观”，640×520 CSS px设计框；小于此尺寸向下自然滚动，固定导航/页脚不得遮盖焦点。主文14px、辅助12px、8px间距网格、按钮高≥28px；正文对比度≥4.5:1，焦点与状态不只靠颜色。优先紧凑、低饱和深色，沿用项目视觉方向，不引入花哨动效。

页脚“关于与更新”打开内部子面板，保留更新/报告问题/赞助三个入口；这些按钮仅显示演示反馈，不能开浏览器。页脚不是第四个设置页。诊断始终在连接页折叠区，代码/端点/凭据表单不在默认首屏。

演示框架中的“悬浮条”“面板”“设置”“场景”切换器位于产品画框外，明确为评审工具，不计入生产导航。无动态远程字体/图片。持续醒目标注“交互原型 · 使用示例数据 · 不连接实际应用”，任何成功态也带“演示”。

悬浮条默认额度摘要；切换工作摘要必须是明确演示操作，不能因选择ChatGPT场景自动切换。点击展开面板，右键或键盘菜单键打开4项菜单：显示模式、暂停/恢复提醒、设置、退出演示。菜单子层仅1层；显示模式含额度摘要/工作摘要/迷你显示，迷你是尺寸开关，和摘要类型分别建模，不能做成互斥三选一。

面板宽320px、最大高度480px；顶部连接边界，中间唯一主操作“打开 ChatGPT（演示）”，底部最近5条及“查看全部”。暂停/恢复为次操作，总计最多1主+2次操作。全部记录最多100条，内部滚动，不能另开大窗口。没有事件时显示空态，不填假时间冒充真实记录。

## 3. 三页细节与完整迁移

连接：顶部ChatGPT卡默认“状态能力未验证”；主要按钮“查看接入说明”（纯内部说明，避免无后端的检查按钮假装真实扫描）。次区“额度来源”“已有工具”默认折叠；诊断独立折叠。未来真实检查入口由WP-004决定，不在本包承诺。

额度来源：合成来源的启用、实例启用、手动凭据保存/验证/删除均有模拟路径；真实密钥输入禁用，旁边仅“使用示例凭据”按钮，字段展示固定掩码。高级自定义来源需明确展开编辑，字段包括名称、轮询1–1440分钟、端点、认证头、前缀、窗口映射与invert；保留Moonshot国内/国际模板及保存/保存验证/删除，所有值都是合成样例。切换设置页不丢未保存草稿，点重置演示才清空。

已有工具：Codex CLI、Claude Code、OpenCode V1独立选择；生成配置后才能模拟安装/移除，切换工具清除旧配置和旧结果并重新禁用操作；配置预览使用虚构安装路径，永不展示真实用户路径。配置检查结果只称“示例配置匹配”，不能等同已登录、已信任或已连接。ChatGPT卡与CLI不合并。

提醒：保留总开关及“测试通知（演示）”；演示暂停15分钟/1小时/直到恢复；连接状态、通知启用、暂停状态和系统提交结果分开显示。关闭提醒或暂停不删除最近事件。系统关闭/勿扰场景标可见性未确认；API失败标提交失败，均不把连接变红。原型不声称能读取系统通知权限，不自动关闭ChatGPT自带通知。

外观：不透明度0.60–1.00步长0.02；宽度240/260/280/300/320/340/360；迷你、开机启动开关仅演示。参数只改变原型内部预览或内存值，不能改变宿主窗口或开机配置。页签切换保留状态；刷新网页恢复固定初始样例，不持久化。

迁移核对14组沿用上游UI-MAP：刷新额度、迷你、诊断、更新、报告、赞助、设置/退出、不透明度/宽度、开机启动、平台/实例/凭据、自定义/模板、CLI接入、任务提醒、检查/测试通知。每组必须在acceptance.md记录原位置→原型入口→模拟动作→结果；其本包变体明确标注，不静默删功能。刷新放面板额度页，有示例冷却禁用态；诊断先预览固定脱敏样例，复制仅演示不写剪贴板。

## 4. 状态模型和场景

使用本地内存对象：view、settingsTab、displayKind、miniMode、drafts、selectedTool、generatedForTool、connectionState、taskState、notificationState、pause、events。taskState仅合成枚举，不得来自应用进程/网页正文/CPU或闲置时间。

connectionState = unverified / absent / conflict / observable_demo / disconnected / unsupported_demo。taskState = unknown / working / needs_attention / ended / failed_demo；授权/输入在样例明示时细分。connection缺少可靠性时摘要始终unknown。多个任务场景使用SAMPLE-A/B和轮次G1/G2，不含真实任务ID；A结束且B工作时不得显示全局已结束；旧G1结束不能改变G2。

固定场景12个：默认未验证、应用缺失、身份冲突、演示工作、授权等待、输入等待、本轮结束、断连、通知暂停、系统可见性未确认、提交失败、A/B交错及旧代晚到。场景切换只能由框架控件触发，清除该场景的事件/时钟但保留演示导航；每个场景有说明与明确预期。真实模式Chat/Work/Codex支持均不确定，原型不得将三者标绿。

暂停时钟采用注入的合成时钟；演示跨重启/回拨只靠场景fixture，不读写系统时钟、不持久化。具体生产单调时钟/UTC规则仍按上游v2 §9.4，原型不能当其通过证据。

## 5. 五条流程与点击预算

从各流程声明的起点计数，点击与右键各算1次，键盘等效；不把测试框架选场景计入产品操作。

U1：设置默认连接→查看接入说明（1）；看到应用身份不等于能力，说明返回不丢焦点。

U2：悬浮条→展开→打开ChatGPT演示（2）；出现“演示：此处将返回应用”，不真的激活窗口。

U3：框架加载等待/结束场景→示例通知按钮（1）→面板；任务状态清晰，演示通知不是系统toast。

U4：悬浮条→展开（1）查看最近5条；查看全部再1；空态/记录顺序和等待标记可理解。

U5：悬浮条→右键（1）→暂停（2）→15分钟（3）；暂停后同位置可恢复（2）。面板展开后暂停15分钟共2。暂停只是通知，不冻结状态变化。

生产体验目标仍为用户5/5无需解释、每流程≤30秒；用户未实际走查只能记录pending，代理完成不能代签。它是Do后的原型接受门槛，不是本轮P/R的阻断前置。

## 6. 技术隔离、失败与可访问性

原型不从原生产页面拷贝执行脚本，只复用必要视觉常量/文字和静态资源。CSP默认拒绝网络：default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self' data:; connect-src 'none'; object-src 'none'; frame-src 'none'; base-uri 'none'; form-action 'none'。导航链接不得指向外站，无 fetch/WebSocket/EventSource/sendBeacon/tauri.invoke；所有按钮type=button。浏览器运行若file策略不支持，报告环境限制，不能为此引入外部托管或放开网络。

不使用localStorage/sessionStorage/IndexedDB、文件写入、真实剪贴板/通知权限或页面标题中的用户内容。关闭原型即可回滚。输入框仅允许无敏感示例字段；清楚提示不要输入真实数据，错误状态只能输出固定码和预设文本。测试注入敏感哨兵仅使用虚构字符串，不能从本机配置取值。

键盘：页签方向键/Home/End、Tab访问可交互项；折叠用button或details/summary，aria-expanded准确；弹层Esc关闭并回触发元素；右键菜单上下键、子菜单左右键、Esc逐层退出，无焦点陷阱。关闭演示面板不强行聚焦别的程序。长中文、200%缩放、320px窄视口均可滚动访问主操作。
