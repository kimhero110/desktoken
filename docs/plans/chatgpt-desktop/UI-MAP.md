# 现有入口迁移清单与交互规格（方案，未实现）

证据来源：src/settings.html 与 src-tauri/src/main.rs 的 build_menu；核对日期2026-09-08。此文件用于消除功能搬迁遗漏，不是桌面端支持证明。

## 入口一一映射

| 现有入口/值 | 新位置 | 兼容要求 |
|---|---|---|
| 立即刷新额度 | 展开面板→额度页→刷新 | 两次点击（展开+刷新）；保留冷却约束，不伪装可立即请求 |
| 迷你模式 | 右键→显示模式；设置→外观 | 同一份设置值；不再创建第三个入口 |
| 复制诊断 | 设置→连接→诊断（折叠） | 先预览脱敏内容再复制，不默认剪贴板写入 |
| 检查更新 | 设置固定页脚“关于与更新” | 稳定版/预览版渠道不改，更新仍由用户操作 |
| GitHub报告问题 | 关于与更新子面板 | 用户点击才开浏览器，不自动上传日志 |
| 赞助 | 关于与更新子面板 | 保留入口，不抢主要操作 |
| 设置、退出 | 右键一级 | 保留退出能力 |
| 不透明度、宽度、迷你模式 | 外观页 | 复用现有合法值与最小60%透明度，不强制覆盖用户宽度 |
| 开机启动 | 外观→启动与显示 | 保留现有注册策略；不自动重新开启 |
| 平台凭据/启用/保存/验证/删除 | 连接→额度来源→具体来源 | 原凭据引用不迁移、不复制密钥；删除仍需明确操作 |
| 自定义监视、模板、轮询、保存验证 | 连接→额度来源→高级自定义来源 | 字段和值不丢；进入编辑态才显示完整表单 |
| CLI工具选择、生成代码、安装/移除 | 连接→已有工具→具体工具→高级接入 | 旧接入保持；不冒充ChatGPT；安装可逆且原文预览保留 |
| 任务提醒总开关 | 提醒页 | 复用原值；新增连接默认未授权观测，不能因旧开关开启就自动扫ChatGPT |
| 接入检查、测试通知 | 连接卡主操作 / 提醒页次操作 | 不把配置检查和真实事件自测合并成“已连接” |

设置一级仅“连接、提醒、外观”；页脚关于入口不作为新导航页。诊断附着于连接，不新增第四页。现有高级CLI用户路径变深是明确取舍，但原功能不可删除。额度刷新由右键迁到面板是新交互成本，U01需实测，与“所有旧操作一步”不兼容，不作该承诺。

## 连接状态与唯一主要操作

| 状态 | 文案 | 主操作 | 副操作 |
|---|---|---|---|
| 未检测到候选 | 未找到所选应用 | 重新检查 | 选择应用（人工纠错） |
| 身份有冲突 | 需要确认目标应用 | 选择应用 | 查看检测依据 |
| 待验证 | 已找到应用，状态能力未验证 | 检查连接 | 诊断 |
| 可观察 | 已连接·仅覆盖已验证场景 | 检查连接 | 断开 |
| 中断 | 暂时无法观察，不代表任务结束 | 重试连接 | 诊断 |
| 不支持 | 当前版本无法可靠识别状态 | 重新检查 | 说明 |

选择/检查不得被实现为永久重试循环。单次检查10秒界限（拟定）后解释超时；后台断线退避1/2/5/15/60秒、上限60秒；版本变化或“不支持”停止自动重试，用户显式重试才重新验证。以上是后续实现约束，S01需据接口限制重评。

## 操作次数与可访问性

- 从悬浮条打开应用：展开+按钮，共2次；有系统通知时点击1次。不会承诺未验证的会话级返回。
- 暂停：展开面板默认暂停15分钟需2次；右键选择时长最多3次。恢复为相同位置、相同动作数。
- 最近5条：展开1次；全部记录再点1次；不要增加独立大窗口。
- 设置：右键+设置2次；从设置默认页到连接主操作1次。
- 键盘：焦点顺序随视觉顺序；按钮有可访问名称；Esc关闭展开面板并回原焦点；已有屏幕边缘定位需限定在工作区。
- 不在后台自动展开、不轮播广告、不把错误反复弹出；被动消息绝不激活窗口。所有小图标都有文字或tooltip，可操作命中区域至少28×28逻辑像素；触控可在后续需求另定，当前不宣称触控优化。

## 用户走查与设计否决

U01至少邀请当前用户走查5条流程，记录成功/失败、步骤和困惑原话（用户同意才记录）；目标5/5无需说明找到入口，每任务≤30秒。不是统计学可用性证明；用户不在场则标待验收，不能主代理代签。

同一页面出现两个相同主操作、原功能无去向、敏感配置在默认页露出、未知显示成功色、后台抢焦点、200%缩放关键按钮不可达，任一情况退回交互稿。视觉稿通过不证明功能可用，原生桌面C阶段仍须实际验证。
