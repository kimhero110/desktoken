# Windows 原生运行链改造

状态：源码实施与本机自动验证完成；尚未发布新版本，真实上游钩子信任迁移、WDSI 复核和签名申请未完成。

## 目标与边界

移除 QuotaBar 自身启动的 PowerShell 子进程和生成钩子的 PowerShell 包装；保留同样的本机额度和任务事件能力。独立维护用的 Defender PowerShell 取证脚本不由应用运行，不属于运行时子进程依赖。其他 AI 工具内部选用的 shell 不由 QuotaBar 控制。

Windows Antigravity 探测使用原生 WMI/网络表接口；仅查询目标进程和 IPv4 回环监听端口，不提升权限，不增加进程内存读取。任务钩子直接调用原生接收器，保持 stdin、UTF-8 和被动输出契约。ACL 测试也改用系统安全 API。

自启动使用用户 Startup 文件夹内的 QuotaBar 快捷方式，由设置动作管理；正常启动不自动写注册表或创建快捷方式。迁移仅删除确认属于当前可执行文件的旧 Run 值，并在快捷方式操作成功后进行；不覆盖未知或其他安装的快捷方式。旧 Run 配置保留到用户触发设置迁移，避免升级后静默丢失自启动。

## 验收要求

- Rust 构建和相关回归通过，Windows 运行时代码及生成钩子不再调用 PowerShell。
- 生成命令经过实际接收器验证；空格与中文路径、畸形及超长输入保持正确，测试不替代上游客户端信任验收。
- Startup 快捷方式可在临时目录创建、读取、删除；未知目标受保护。测试不写真实 Startup/Run 配置。
- 原生 ACL 测试保留继承和受保护权限的检查，不以删除测试换取通过。
- 文档说明旧钩子需要重新生成和信任确认，不自动替用户批准新定义。
- Defender 旧版本复核、代码验证和签名申请各自报告实际状态，不将其中一个成功等同于其余成功。

- debug 与 release 构建成功；两种构建的事件桥及生命周期测试通过，包含空格/中文路径、Codex cmd 原样传参、Claude 参数数组直启、3 会话与 7 通知候选。
- release 产物 SHA-256：`a267daccfff0be097c2c3e01038914c9c5f42b431ef67d221924a236f4c44659`。本机 Defender `1.459.111.0`、实时保护开启下，自定义扫描返回 0 并明确未检出。该产物为本地验证构建，不是 beta.2 发布页的既有文件。
- 未在真实用户 Startup/Run 项上做测试迁移；未自动重写已信任钩子；未宣称真实 Antigravity 服务端额度回归或其他客户端版本均已验收。
- Windows 应用运行链和生成钩子已无 PowerShell 调用；macOS 原有 `ps/lsof` 不属于这次 Windows 改造。
